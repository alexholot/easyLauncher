# Стандартный фон главного экрана

Сюда можно положить `default-bg.jpg` — фон «Стандартный» на экране «Играть».

Используйте только снимок, права на который понятны: например, **свой** скриншот из игры.
Перед публикацией сверьтесь с актуальными Minecraft Usage Guidelines (minecraft.net/usage-guidelines)
и не выдавайте лаунчер за официальный продукт Mojang.

Не кладите сюда:
- случайные картинки из интернета;
- сгенерированные изображения, выдавая их за кадр из игры.

Если файла нет, лаунчер показывает нейтральный фон. Это поведение по умолчанию.
