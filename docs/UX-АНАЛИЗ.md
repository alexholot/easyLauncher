# Анализ лаунчеров и решения для easyLauncher 3.0

## Как собиралась информация

Источник — официальная документация, вики и журналы изменений (ссылки ниже).

**Не проверено:**
- приложения не запускались;
- их интерфейс не сравнивался по скриншотам;
- время сценариев не замерялось.

Из этого следуют два ограничения:
- Вывод о том, «как это выглядит», сделан по текстам документации и может отставать от текущих версий.
- Детали вида «где именно кнопка» не утверждаются.

## Что общего у удобных лаунчеров

| Лаунчер | Главная сущность | Запуск | Моды | Что взяли |
|---|---|---|---|---|
| Официальный Minecraft Launcher | Установка (Installation): версия + папка игры | Вкладка «Играть» с выбором установки и большой кнопкой; список установок со своей кнопкой запуска | нет | Главный экран: выбранная сборка + «Играть»; карточки сборок с кнопкой запуска |
| Prism Launcher | Экземпляр (instance) | Запуск экземпляра из списка | В экземпляре → «Моды»: включение/выключение флажком, «Скачать моды» из Modrinth/CurseForge, обновление, учёт зависимостей | Моды — внутри сборки; включение без удаления; проверка обновлений |
| Modrinth App | Экземпляр в библиотеке | Из библиотеки | Каталог с фильтрами по версии/загрузчику/категории и «скрыть установленные»; установка в выбранный экземпляр с зависимостями; подбор последней подходящей версии | Каталог с целевой сборкой; «Установить» сам подбирает релиз и зависимости |
| CurseForge App | Профиль (сборка) | «Играть» у профиля | «Добавить контент» в профиль; при установке — выбор нового или существующего профиля; экспорт профиля | Экспорт/импорт сборки; цель установки видна явно |
| ATLauncher | Экземпляр | «Играть» у экземпляра | «Добавить моды» / «Редактировать моды» у экземпляра | Подтверждение: модель «сборка → моды → запуск» общепринята |

Вывод: во всех лаунчерах центр — **сборка** (установка, экземпляр, профиль), а не мир. Моды и миры принадлежат
сборке, запуск — у сборки. Игра с друзьями ни в одном из них не встроена в главный сценарий.

## Решения

1. **Сборка — главная сущность.** Миры лежат внутри неё (`game/saves`). Поэтому несовместимой сборкой мир не
   открыть.
2. **«Играть» = главное меню Minecraft.**
   - Без сервера, EULA, генерации мира и повторных подтверждений.
   - Вход сразу в мир — отдельная кнопка у мира.
   - Подтверждение нужно только при реальных изменениях: смене версии игры, удалении модов, откате.
3. **Навигация — шесть разделов в боковой панели:** Играть, Сборки, Моды, Миры, С друзьями, Настройки. У каждого
   действия один путь. Помощник — отдельная кнопка.
4. **Каталог.**
   - Сверху всегда видна целевая сборка.
   - Фильтры по умолчанию совместимы с ней.
   - «Установить» прямо в списке, без диалога для простых случаев.
   - Карточка мода не сбрасывает поиск, фильтры и прокрутку.
5. **Моды внутри сборки:** поиск, включение/выключение, обновление, закрепление версии, удаление, «Вернуть прежний
   состав».
6. **С друзьями — отдельный сценарий.** Сборка + мир → сессия → приглашение. Состояние сервера, участники и
   маршрут видны только там. Без сервера приглашений лаунчер прямо говорит, что работает только локальная сеть.
7. **Фоны и обложки — только честные источники.**
   - Источники: своя картинка, обложка сборки, скриншот сборки.
   - Скриншот становится обложкой мира автоматически, только если по журналу игры связь однозначна.
   - Ручной выбор закрепляется.
   - Выдуманных или случайных картинок нет. Нарисованный кодом «пейзаж» прототипа убран.
8. **Помощник — по желанию.** Всё основное работает без него. Это проверено отдельным сценарием.
