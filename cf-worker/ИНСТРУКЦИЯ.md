# Каталог CurseForge через Cloudflare Workers (бесплатно, без VPS)

Прокси хранит ключ CurseForge у Cloudflare и добавляет его к запросам лаунчера.
В лаунчере и у игроков ключа нет. Бесплатный тариф Workers — до 100 000 запросов в день.

## 1. Создать Worker
1. Зарегистрируйся на https://dash.cloudflare.com (бесплатно, карта не нужна).
2. Слева: **Compute (Workers) → Workers & Pages → Create** (или «Create application»).
3. Выбери **Start with Hello World!**, имя: `easylauncher-curseforge` → **Deploy**.
4. Нажми **Edit code**, удали весь код и вставь содержимое файла `worker.js` → **Deploy**.

## 2. Добавить ключ (секретом)
1. Открой Worker → **Settings → Variables and Secrets → Add**.
2. Type: **Secret**, Variable name: `CF_API_KEY`, Value: ключ из console.curseforge.com → API keys.
3. **Deploy** (или Save and deploy).

## 3. Проверить
Открой в браузере адрес Worker с `/health` на конце, например:
`https://easylauncher-curseforge.ИМЯ.workers.dev/health` → должно быть `{"ok":true,"curseforge":true}`.

## 4. Подключить лаунчер
easyLauncher → **Настройки → Сеть → Каталог CurseForge** → вставь адрес Worker (без `/health`) → Сохранить.
Чтобы друзьям не вводить адрес вручную, его можно вшить в сборку: в `package.json` поле
`"easylauncher": { "cfProxy": "https://..." }`, затем `npm run dist:win`.

## 5. Обновить Worker (когда меняется `worker.js`)
С версии лаунчера 4.3.0 прокси умеет искать файл мода по отпечатку — так лаунчер узнаёт моды CurseForge,
положенные в папку вручную, — и отдаёт несколько модов одним запросом (картинки модов CurseForge в сборке).
Старый прокси этого не умеет: лаунчер работает, но такие моды остаются в списке «из папки».
1. https://dash.cloudflare.com → **Workers & Pages** → `easylauncher-curseforge` → **Edit code**.
2. Удали весь код и вставь новое содержимое файла `worker.js` → **Deploy**. Ключ `CF_API_KEY` трогать не нужно.
3. Проверь `https://easylauncher-curseforge.ИМЯ.workers.dev/health` → в ответе должно быть `"post":["/v1/mods","/v1/mods/files","/v1/fingerprints/432"]`.

## Ограничения
- Прокси пропускает только чтение каталога Minecraft: поиск, мод, файлы, категории — и три пакетных запроса
  (несколько модов, несколько файлов, поиск по отпечатку), в которых к CurseForge уходит только список чисел.
  Ответы на обычные запросы кэшируются на 5 минут.
- Адрес Worker не секретный: им может воспользоваться любой, кто его узнает, но только для поиска модов Minecraft.
  Если увидишь в Cloudflare подозрительно много запросов — включи там Rate limiting или смени имя Worker.
- Названия пунктов в панели Cloudflare могут немного отличаться — ищи Workers, Variables, Secret.
